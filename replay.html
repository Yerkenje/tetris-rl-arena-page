Playback is synchronized by piece number, not by animation length. At move 0 the board is empty. The progress slider seeks both agents together; if one game ends early, its final board stays frozen. In a noisy replay, the translucent gold ghost is the agent's intended placement while the solid piece shows where execution noise actually put it. The red flash marks a successful shift; the amber flash marks a blocked shift, where the intended placement was kept. Use Prev/Next error for successful shifts and Prev/Next blocked for blocked shifts.

Static HTML, CSS and JavaScript. No model calls, no external libraries. Replay data: recorded simulations from the final verified run. Paper and results.
